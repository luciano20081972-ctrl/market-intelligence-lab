# Outcome Attribution

v0.13 extends attribution to immutable forecast outcomes using bounded reason codes for mechanisms, regimes, revisions, stale data, redundancy, alternatives, skeptic warnings, scenario realization, unmodeled events, benchmark effects, timing, magnitude, direction, and over/underconfidence. Attribution is explanatory and does not establish causality.

Outcome attribution records why a study succeeded or failed using bounded categories and evidence references. It supports learning from validation quality, data coverage, robustness, and lack of out-of-sample persistence without rewriting the original experiment or claiming causality.
