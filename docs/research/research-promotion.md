# Research promotion

Promotion is sequential and versioned: DRAFT → EVIDENCE_CHECKED → IMPLEMENTED → LEAKAGE_CHECKED → BACKTESTED → WALK_FORWARD_PASSED → ROBUSTNESS_PASSED → OOS_PASSED → PAPER_ELIGIBLE. Required gates are configured in `config/hypothesis-factory.yaml`; direct jumps are rejected. Each event records decision, reasons, evidence, actor, timestamp, and policy version. No live-trading status exists.
