# Runtime reasoning provider

`ResearchReasoningProvider` defines hypothesis generation, mechanism critique, evidence suggestions, and feature-specification suggestions without naming a vendor. The deterministic provider drives ordinary tests and produces materially different archetypes. An optional callback adapter can host a configured runtime model and has a clean unavailable state. It receives bounded data, never credentials, and cannot execute shell commands, arbitrary SQL, or filesystem operations. Default fixture usage is zero API calls and zero tokens.
