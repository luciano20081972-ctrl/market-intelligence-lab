# Memory Applicability

Applicability states where a lesson may transfer: entity or business-model characteristics, sector, feature domains, period, and regime. It is evidence metadata, not a universal claim. An exact mechanism match outside the recorded context is surfaced for review rather than silently treated as proof.

The reference set demonstrates different behavior for semiconductors, airlines, and an agricultural cooperative. Applicability is stored with the memory and returned in detail/search APIs.
