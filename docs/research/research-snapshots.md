# Research snapshots

An immutable feature snapshot captures universe version, entity population, feature-set version, exact feature values, as-of time, application SHA, migration head, source/graph/routing/policy context, seeds, and warnings. A screening run adds decisions, funnel counts, budget usage, reasons, and a checksum. These snapshots are the future input boundary for backtests, model training, hypothesis work, and dossiers; those future systems must not silently resolve newer data.
