# Vendor evaluation policy

Evaluate security model, official API stability, current limits/pricing, data classification, subprocessors, residency, retention/deletion, credential scope, export, replacement, outage behavior, lock-in, commercial terms, and budget alerts. Record a verification date and owner. Recheck quarterly and before activation or plan changes.

An entry may move to `active` only after threat-model review, least-privilege credentials, secret-manager placement, failure testing, and an exit rehearsal. Free availability alone is never a selection criterion.
