# Free-tier services

The machine-readable registry is `config/infrastructure-services.yaml`. It covers GitHub, Supabase, Cloudflare, Sentry, Better Stack, Codecov, and Resend, with official documentation/pricing links and a 2026-07-30 verification date.

`free-for.dev` is a discovery catalog only. Official vendor documentation and pricing are authoritative. Limits and terms may change without this repository changing. No account is created and no service is activated by repository setup. Financial-data licensing is separate from infrastructure pricing.

Current status: GitHub active; Supabase evaluating; Cloudflare, Better Stack, and Codecov proposed; Sentry and Resend deferred. Every production-critical service requires an exercised export and replacement plan before private beta.
