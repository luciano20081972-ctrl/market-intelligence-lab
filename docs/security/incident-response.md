# Incident response

Detect through health, audit, provider, worker, dependency, and optional scrubbed telemetry signals. Triage severity and affected workspaces without copying secrets into tickets. Contain by disabling users/providers, rotating scoped credentials, revoking sessions where supported, pausing imports, and preserving logs. Eradicate the root cause, restore from verified exports, notify affected parties according to legal policy, and document a blameless post-incident review.

Never amend audit history. Record administrative recovery as a new event. Test credential rotation, database restore, provider disablement, and vendor exit before private beta.
